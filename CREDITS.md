# Créditos

**SELENE** é construída sobre o [opencode](https://opencode.ai), um agente de programação de
terminal de código aberto. Sem o trabalho da equipe original, este projeto não existiria.

---

## Projeto original

|---|---|

| **Site** | https://opencode.ai |

| **Licença** | MIT |
| **Copyright** | © 2025 opencode |

A SELENE é um **fork** — pega a base do opencode e veste a identidade visual, o nome e os fluxos de
trabalho da Naoriky. Boa parte do motor (execução de ferramentas, sessões, provedores, TUI, servidor
local) vem direto do projeto original.

## O que a SELENE mudou

- Nome, marca, ícone (orbe), paleta de cores (`#8b5cf6` / `#22d3ee` / `#07070d`)
- Wordmark ASCII próprio no terminal
- Nomes de pasta e configuração (`selene` em vez de `opencode`)
- Comandos e atalhos (`sel`, `selene.*`)
- Camada de identidade própria do agente (nome escolhido pelo dono)

## O que continua sendo do opencode

- Arquitetura cliente/servidor local
- Motor de execução de agentes e ferramentas
- Integração com dezenas de provedores de modelo
- Interface de terminal (TUI) e componentes base
