# Changelog

## 0.1.3
- Added a SELENE icon to the activity bar, with a panel of quick actions.
- Fixed the terminal tab icon so it no longer shows the default icon.
- Fixed command icons that were missing from the package.

## 0.1.1
- New icon: the SELENE logo, optimized for the extensions list.
- Credits to the original project added in `CREDITS.md`.

## 0.1.0
- First release.
- Opens SELENE in a terminal tab alongside your code (`Ctrl+Alt+Esc`).
- Downloads the agent automatically on first run and adds it to the PATH.
- Command `SELENE: Install` to download or update the agent.
- Inserts a reference to the current file or selection (`Ctrl+Alt+S`).
